Methodology & Data Glossary

We measure serialization performance across multiple dimensions to ensure that improvements in speed do not come at the cost of memory efficiency or cold-start latency.

1. Latency & Throughput

Serialization Latency (Lower is Better)
Time taken to convert a Python object graph into a byte or string representation. Measured in microseconds (µs) per operation.
XL Throughput (Higher is Better)
Processing speed when handling extremely large datasets (500,000 objects). Measured in Megabytes per second (MB/s).

2. Memory & Efficiency

Peak Memory Usage (Lower is Better)
Maximum RAM consumed during serialization. Streaming mode targets O(1) memory usage regardless of dataset size.

3. Data Scenarios

  • Simple: Flat objects with primitive types.
  • Complex: Objects with nested lists, maps, enums, and dates.
  • Nested: Multi-level recursive hierarchies.
