Methodology & Data Glossary

We measure serialization performance across multiple dimensions to ensure improvements in speed don't sacrifice efficiency. All data is collected on standardized AMD EPYC runners.

Serialization Latency (Lower is Better)
Time to convert Python object graph to JSON/Binary. Measured in µs per op.
XL Throughput (Higher is Better)
Processing speed for 500k objects in MB/s.
Peak Memory Usage (Lower is Better)
Max RAM used. Streaming mode targets O(1) memory.
Supported Formats
JSON, YAML, TOML, MsgPack, CBOR, BSON, Pickle.
